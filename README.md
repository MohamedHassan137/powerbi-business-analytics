# Power BI Business Analytics Dashboard

##  Project Overview

A comprehensive **Power BI** interactive dashboard designed for business intelligence and performance monitoring. This report provides deep insights into sales, orders, customer analytics, location performance, and key business metrics.

##  Key Features

- **Sales & Orders Analysis**
- **Geographic Performance** (Location-based insights)
- **Executive KPIs & Trends**
- **Gender Equality & HR Metrics** (Diversity analytics)
- **Interactive Visualizations** with cross-filtering
- **Professional Design** with modern theming

##  How to Use

1. Download the `project.pbix` file
2. Open it with **Power BI Desktop** (Free)
3. Explore the interactive pages and slicers
4. Connect to your own data source if needed

**Recommended:** Use the `.pbip` format for version control and collaboration.

##  Technologies Used

- **Power BI Desktop**
- DAX (Data Analysis Expressions)
- Power Query (M Language)
- Modern Power BI Theming
- Advanced Visualizations
